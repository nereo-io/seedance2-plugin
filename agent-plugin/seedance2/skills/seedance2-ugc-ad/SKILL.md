# UGC ad

Read [workflow](references/workflow.md) once per task: tool order, prices, waiting, uploads, and what to do when the server is not connected. Read [Seedance prompting](references/seedance-prompting.md) before writing a video prompt.

## Steps

1. Agree the script first: hook (first 2 s), one benefit, call to action. Keep spoken lines short — about 2–3 words per second.
2. Presenter: use reference images of the presenter if the user has them (and has the right to use the likeness); otherwise describe a generic creator. Never imitate a real, identifiable person without the user confirming they have permission.
3. Product: reference images of the product, details repeated in the prompt.
4. Settings: 9:16, audio on, handheld or selfie framing, natural light, Seedance 2.5.
5. Put the dialogue in quotes and say who speaks: `She says: "I didn't expect it to be this light."`
6. Quote the price, generate, poll, deliver. Offer a second hook variant rather than re-rendering the whole ad.
